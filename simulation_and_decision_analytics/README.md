# Simulation and Decision Analytics

This repository contains analytical coursework and operational modeling projects focused on simulation, process optimization, and data-driven decision-making.

Key areas include:

- process and system simulation
- operational analytics
- queueing and workflow analysis
- decision optimization
- performance evaluation and resource allocation
- analytical modeling using Python, R, and Excel Solver

The projects emphasize practical operational problem-solving, quantitative reasoning, and simulation-based decision analysis within business and management systems.
