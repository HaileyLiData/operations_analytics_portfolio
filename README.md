# Operations Analytics Portfolio

This repository contains graduate-level projects and analytical coursework focused on operations analytics, optimization modeling, simulation, and quantitative decision-making.

The work combines mathematical modeling, operational problem-solving, and analytical interpretation using tools such as Python, R, Excel Solver, and optimization frameworks.

## Areas of Focus

- Linear programming and constrained optimization
- Duality and sensitivity analysis
- Transportation and network optimization
- Quantitative decision modeling
- Operations research methodologies
- Data-driven analytical workflows
